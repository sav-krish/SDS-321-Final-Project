    What this assumes

    • The student either knows the topic or is guessing. Answers are independent once we know which.
    • The start belief of 0.30 is an assumption for a beginner class, not measured data.
    • The quiz stops at 95% sure (mastered) or 5% sure (not mastered), or after 12 questions.
    • All students here are simulated, so no real learner data is used.
